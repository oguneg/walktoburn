# walktoburn

A tiny calculator that shows how long it takes to burn 100 calories at different walking paces and inclines — and why a slower, steeper walk often beats a fast flat one.

Static site, no build step. Enter height/weight/gender, then use the pace and incline sliders to see time-to-burn, calories/min, METs, and steps, plus a comparison against common walk/jog presets.

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploy

Hosted via GitHub Pages from the `main` branch root.
